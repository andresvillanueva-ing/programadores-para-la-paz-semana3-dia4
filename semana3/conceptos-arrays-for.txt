Responde con tus propias palabras.

1. ¿Qué es un array en JavaScript?

Respuesta: Es una estructura de datos que permite almacenar varios 
    valores en una sola variable.

2. ¿Para qué sirve guardar varios datos en un array?

Respuesta: Sirve para organizar y manejar múltiples datos de forma ordenada 
y fácil de recorrer o modificar.

3. ¿Qué tipo de información comunitaria podría guardarse en un array?

Respuesta: Se podrían guardar propuestas, nombres de participantes, 
votaciones o reportes ciudadanos.

4. ¿Qué hace un for tradicional?

Respuesta: Permite repetir un bloque de código un número determinado de veces.

5. ¿Qué representa la variable i en un for tradicional?

Respuesta: Representa el contador que indica la posición o número de iteración del ciclo.

6. ¿Qué significa .length?

Respuesta: Es una propiedad que indica la cantidad de elementos que tiene un array.

7. ¿Qué hace for...of?

Respuesta: Permite recorrer directamente los elementos de un array sin usar índices.

8. ¿Qué diferencia inicial encuentras entre for y for...of?

Respuesta: El for usa un contador e índices, mientras que for...of recorre directamente 
los valores del array.

9. ¿Qué hace el comando npm run revisar?

Respuesta: Ejecuta un script llamado “revisar” definido en el archivo package.json del proyecto.

10. ¿Cómo puede ayudar un array organizado a la participación ciudadana?

Respuesta: Ayuda a organizar información como propuestas o opiniones de la comunidad, facilitando 
su análisis, seguimiento y toma de decisiones.
